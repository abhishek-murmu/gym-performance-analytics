# GYM_TRACKer

Gym performance analytics and tracking — data analysis utilities and scripts for tracking workouts and player statistics.

## Features
- Data analysis scripts for gym session logs
- CSV import and basic visualization (Jupyter/Matplotlib)

## Getting Started
1. Clone the repository:

```bash
git clone <repo-url>
```

2. Inspect or run analysis scripts (Python 3.8+ recommended):

```bash
python analysis.py
```

## Project structure
- `analysis.py` — main analysis script
- `data/` — sample datasets
